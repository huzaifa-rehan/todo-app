# todo-app

A very simple to-do list app: add tasks and see them all in one list.

## Plan (v1)

- Add a task by typing it and pressing Enter or clicking **Add**
- List all tasks
- Tasks are kept after the page is closed or refreshed (saved in the browser's `localStorage`)

Built with plain HTML, CSS and JavaScript. No build step: open `index.html` in a browser.
